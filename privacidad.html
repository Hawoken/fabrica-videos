Política de privacidad

Última actualización: 25 de octubre de 2026.

«Fábrica de vídeos» es una herramienta personal. Solo la usa su autor, con su propia cuenta de Google y su propio canal de YouTube.

Qué datos usa

  • Permiso para subir vídeos al canal del autor (youtube.upload).
  • Permiso de solo lectura para consultar el estado y las estadísticas de esos vídeos (youtube.readonly).

Qué no hace

  • No accede a cuentas ni datos de otras personas.
  • No vende, comparte ni cede datos a terceros.
  • No usa los datos de las API de Google para publicidad ni para entrenar modelos.

Dónde se guardan

Las credenciales de acceso se guardan cifradas en tránsito y con acceso restringido en un servidor privado del autor. Se pueden revocar en cualquier momento desde myaccount.google.com/permissions.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
